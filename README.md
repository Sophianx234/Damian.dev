## 🚀 Getting Started

Clone and run the project locally:

```bash
# Clone the repository
git clone https://github.com/Sophianx234/Damian.dev.git
cd Damian.dev

# Install dependencies
npm install   # or yarn / pnpm / bun

# Run dev server
npm run dev
```

Visit: **http://localhost:3000**
